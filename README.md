# hist — історія сесій Claude Code → Markdown

Термінальний інструмент з меню: вибираєш проєкт або сесію стрілками, підтверджуєш — і отримуєш читабельний Markdown у `~/Code/history/<тека>/`. Працює з **будь-яким** проєктом, без пресетів і прапорів. Формат такий самий, як у `~/Code/history-to-md.js`.

Як усе влаштовано і як розширювати — [ARCHITECTURE.md](ARCHITECTURE.md).

## Встановлення

```bash
cd ~/Code/history-cli
./build.sh install      # vet + тести + збірка → ~/go/bin/hist
./build.sh dist         # готові файли для macOS і Linux (arm64, amd64) → dist/
```
Потрібен Go 1.22+.

## Інтерактивно

```bash
hist                    # головне меню
hist -p .               # одразу сесії поточної теки
hist -p ~/Code/my-app   # одразу сесії конкретного проєкту
```

Клавіші: **↑↓** вибір · **Enter** відкрити · **q / Esc** назад · **PgUp/PgDn, Home/End** у таблицях · **/** фільтр · **1-9** швидкий вибір у меню · **Ctrl+C** вихід. У полях вводу: **Tab** доповнює шлях, **Ctrl+U** очищає.

| Пункт меню | Що робить |
|---|---|
| Поточна тека | з'являється, якщо в теці запуску є сесії |
| Останні сесії (всі проєкти) | таблиця: дата, розмір, ID, шлях проєкту, назва/перше повідомлення |
| Проєкти | усі проєкти з сесіями → сесії проєкту |
| Проєкт за шляхом… | ввести шлях (Tab-доповнення) → сесії проєкту |
| Пошук по історіях | текст діалогів і назви сесій, без регістру; таблиця з кількістю збігів і сніпетом |
| Експорт за ID | хеш зі списку (4+ символи), повний ID або шлях до `.jsonl` |
| Зберегти всі сесії проєкту… | усі сесії проєкту за один раз |
| Налаштування | тека для історій, підпис твоїх повідомлень |

У таблиці сесій проєкту є дії **» Зберегти всі сесії** і **» Пошук у цьому проєкті**.

Збереження: режим (**повний** з інструментами / **діалог** / **обидва**) → тека (запропонована, можна змінити або дати абсолютний шлях) → список файлів → **y**. Тека запам'ятовується для проєкту.

## Команди (без меню)

```bash
hist ls                               # останні 30 сесій з усіх проєктів
hist ls -p ~/Code/my-app -n 100
hist projects
hist search database migration       # таблиця + сніпети
hist search auth -p .
hist export 1a2b3c4d --full           # за хешем
hist export latest -p . --both        # найновіша сесія, обидва варіанти
hist export --all --full -p ~/Code/my-app
hist export 1a2b3c4d --dir notes --out summary.md
hist help
```

Прапори: `-p/--project <шлях>`, `--full`, `--both`, `--dir <тека|абсолютний шлях>`, `--out <назва.md>`, `-n <кількість>`, `--temp` (показати тимчасові/eval-проєкти).

## Куди пише

```text
~/Code/history/<тека>/YYYY-MM-DD-<id8>.md        # діалог
~/Code/history/<тека>/YYYY-MM-DD-<id8>.full.md   # з інструментами
```
Дата — остання активність сесії (UTC). Налаштування: `~/.config/history-cli/config.json` (`history_root`, `user_label` — за замовчуванням системний логін, `folders` — проєкт → тека).
